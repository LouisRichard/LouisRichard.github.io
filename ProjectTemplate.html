[Game Library]

[Category] Development
[Timespan] 2020
[Status] Finished

The Game Library project was designed to catalog and manage a user’s video game collection efficiently. Built using the C# .NET framework, the system connects to a lightweight SQLite database, allowing users to browse, search, and categorize games. The UI design is inspired by retro command-line aesthetics blended with modern utilitarian layout principles.
